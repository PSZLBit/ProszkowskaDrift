# Decision Entry Template

Copy this row into `05-architecture-decisions/decision-log.md` (newest on top).

```text
| YYYY-MM-DD | D-XX | Short decision statement. | Decided | Owner |
```

Rules:

- Keep the statement to one sentence.
- Link to an ADR file when the decision is larger than one sentence.
- Never delete history; add a new dated row to change a decision.
